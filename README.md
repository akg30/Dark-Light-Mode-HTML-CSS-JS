# Dark-Light-Mode-HTML-CSS-JS

## Overview
This project implements a simple Dark/Light mode toggle for a website using HTML, CSS, and JavaScript. It allows users to switch between dark and light themes dynamically, enhancing the user experience and making the website more customizable. The toggle is built with smooth transitions for a seamless experience.

## Features
- **Dark Mode & Light Mode Toggle**: Easily switch between light and dark themes with a click of a button.
- **CSS Styling**: The light and dark themes are styled using CSS variables, ensuring consistency across the site.
- **JavaScript Functionality**: JavaScript handles theme switching and stores the user's preference in the browser for a persistent experience.
- **Smooth Transitions**: Enjoy a smooth, animated transition between themes for a better user experience.
